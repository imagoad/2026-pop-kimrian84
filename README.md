# 📊 인구 데이터 Streamlit 대시보드

행정안전부·통계청 인구 데이터를 활용해 만든 두 개의 Streamlit 앱입니다.
둘 다 [Streamlit Cloud](https://share.streamlit.io)에 배포하는 것을 전제로 만들었습니다.

---

## 앱 1. 연령별 인구현황 대시보드 (`app.py`)

행정안전부 **주민등록 연령별 인구현황(월간)** CSV를 읽어, 지역별 연령 구조를 비교하고
인구 피라미드를 그려주는 대시보드입니다.

### 주요 기능
- 연령별(0세~100세 이상) × 성별(계/남/여) 인구수 컬럼 자동 파싱
- 지역명 검색(텍스트 입력) + 다중 선택(멀티셀렉트)으로 여러 지역 비교
- 선택 지역들의 **연령별 인구 구조 꺾은선 그래프** (Plotly, 5세 단위 묶기 옵션 포함)
- 첫 번째 선택 지역의 **인구 피라미드** (남/여 대칭 막대그래프)
- 원본 데이터 테이블 보기

### 데이터
- 코드와 **같은 폴더**에 있는 CSV 파일을 직접 읽습니다 (파일 업로드 없음).
- 파일명: `202607_202607_연령별인구현황_월간.csv`
  (행정안전부에서 내려받은 파일명 그대로 사용 — 다른 월/연도 파일을 쓰려면 코드 상단의
  `DATA_FILE` 변수를 원하는 파일명으로 바꿔주세요.)
- 인코딩: `cp949` (실패 시 `utf-8`로 자동 재시도)

### 필요 라이브러리 (`requirements.txt`)
```
streamlit
pandas
plotly
```

## 앱 2. 인구 퍼짐 & 유사 지역 찾기 (`main.py`)

전국 읍·면·동 단위 인구 데이터를 인터넷에서 직접 불러와,
**총인구의 분포(퍼짐)**를 살펴보고 **인구구조가 비슷한 지역**을 찾아주는 초보자용 앱입니다.

### 주요 기능
1. 총인구 요약 통계 `describe()` 표
2. 총인구 히스토그램 (Plotly, 확대/축소 가능)
3. 총인구 상자그림 (Plotly, 이상치 지역 확인 가능)
4. **인구구조 Top 5 유사 지역 찾기**
   - 지역 검색(텍스트) + 선택(드롭다운)으로 기준 지역 지정 (읍·면·동 단위까지 선택 가능)
   - 나이별 인구 **비율**(구조) 벡터의 유클리드 거리로 전국에서 가장 비슷한 지역 5곳 탐색
   - 기준 지역과 Top 5 지역의 연령 구조를 겹쳐 그린 Plotly 꺾은선 그래프

### 데이터
- URL에서 직접 읽어오므로 별도 파일을 저장소에 올릴 필요가 없습니다.
- 출처: `https://raw.githubusercontent.com/greatsong/modudata/main/data/population_yearly.csv.gz`
- 압축 파일(.csv.gz)이지만 `pd.read_csv(url, compression="gzip")`로 바로 읽힙니다.
- `연도` 컬럼 중 가장 최신 연도만 사용하며, 이미 읍·면·동 단위 데이터라 시도·시군구 합계 행은 섞여 있지 않습니다.
- `남_`으로 시작하는 모든 열 + `여_`로 시작하는 모든 열을 행마다 더해 `총인구` 컬럼을 새로 만듭니다.

### 필요 라이브러리 (`requirements.txt`)
```
plotly
```
(streamlit·pandas·numpy는 기본 설치되어 있다고 가정하고 제외했습니다.)

## 폴더 구조 예시

```
your-repo/
├── app.py                                    # 앱 1: 연령별 인구현황 대시보드
├── main.py                                    # 앱 2: 인구 퍼짐 & 유사 지역 찾기
├── 202607_202607_연령별인구현황_월간.csv        # 앱 1 전용 데이터 (같은 폴더에 필요)
└── requirements.txt                           # 배포하려는 앱에 맞게 선택/작성
```

> 두 앱은 서로 다른 `requirements.txt`가 필요합니다.
> 하나의 저장소에서 앱 1과 앱 2를 각각 별도로 배포한다면,
> 저장소를 앱별로 나누거나 `requirements.txt`를 두 앱 모두에 필요한 패키지
> (`streamlit`, `pandas`, `plotly`)로 합쳐서 사용하세요.

## Streamlit Cloud 배포 방법

1. 위 파일들을 GitHub 저장소에 커밋 & 푸시합니다.
2. [share.streamlit.io](https://share.streamlit.io) 접속 → **New app** 클릭
3. 저장소 / 브랜치 / 실행할 파일(`app.py` 또는 `main.py`) 지정
4. **Deploy** 클릭 후 몇 분 기다리면 배포된 URL이 생성됩니다.
